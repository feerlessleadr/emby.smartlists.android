## v0.3.0

**The editor now covers everything the web page's list form offers**

- **Playlists for several users:** pick users, or "a playlist for every user"; make a single-user playlist public. Removing a user deletes their playlist, adding one creates it, and the others keep theirs.
- **Collections** can change whose watch state their rules use.
- **Schedules:** refresh at set times (daily, weekly, monthly, yearly, every so often) and show/hide the list at set times.
- **On the Emby list:** sort title, description, tags and favorite.
- **Custom images** for existing lists: choose a picture from the phone's photo picker, see a preview, replace or delete it.
- **Bumpers** for playlists, with their own rules, order and spacing.
- **Advanced options:** include extras, match collections/playlists by their items, replace items with their collection, pick one group at random, and what a "similar to" rule compares.
- **Per-rule options:** check for a specific user, include items with no date, runtime unit, only the default audio track, look at the parent series or album, collection search depth.

Rarely used sections (Schedules, On the Emby list, Advanced, Bumpers, Images) fold away and show a one-line summary while closed.

Needs the SmartLists plugin 0.1.9 or newer. Update through Obtainium or download the APK below.
