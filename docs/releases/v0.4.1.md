## v0.4.1

**Security fixes from a review of the app**

- The app no longer follows redirects, so the access token (and the password at sign-in) can never be re-sent to another host by a misbehaving server or proxy.
- **Sign out** now also ends the session on the server and deletes the stored encryption key.
- The widget's tap can no longer be triggered by other apps on the phone.
- Ids and file names that come from the server are checked before they are put into a request.
- A shared list that is huge or absurdly nested is refused instead of crashing the app, and pictures from the server are size-limited. Backups are saved straight to the chosen file instead of through memory.
- A release build can no longer be signed with the debug key by accident.

Works with plugin 0.1.9 or newer; the preview needs 0.1.10 or newer (plugin 0.1.11 has its own security fixes). Update through Obtainium or download the APK below.
